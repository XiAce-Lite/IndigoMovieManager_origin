# IndigoMovieManager

WhiteBrowser 互換を目指した、Windows 向けの動画管理ツールです。  
既存の管理ファイル（`.wb` 等）やサムネイル資産をなるべくそのまま使えます。

より高機能な版: [IndigoMovieManager](https://github.com/XiAce-Lite/IndigoMovieManager)

開発者向けの技術仕様: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

---

## 動作環境

- Windows 10 以降（x64）
- [.NET 8 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0)（ソースからビルドして実行する場合）
- 配布版（GitHub Releases）を使う場合はランタイムの別途インストールは不要なことが多いです

Linux / macOS では動作しません。

## WhiteBrowser からの移行・初回テスト

本番データを壊さないため、次の手順を推奨します。

### バックアップとコピーで試す

1. **管理ファイル（`.wb`）はコピーして試す** — 原本を直接開かず、コピーしたファイルで動作確認してから本番へ切り替える
2. **`Thum` フォルダと `bookmark` フォルダをバックアップ** — WhiteBrowser で使っていたサムネイル・ブックマーク資産は、試す前にコピーまたはバックアップを取る
3. **初回は軽い `.wb` で試す** — レコード数が少ない DB、または軽いスキン（後述）で慣れてから本番 DB へ

### サムネイルフォルダ（`Thum` と `Thumb`）

- WhiteBrowser の既定フォルダ名は **`Thum`**
- 本アプリの未設定時の既定は、exe 横の **`Thumb/<DB名>/`**
- DB の個別設定に WhiteBrowser と同じパスが入っていれば、そのパスを参照できます
- 新規生成されるサムネの出力先が混在しないよう、移行時は個別設定（ハンバーガー → **個別設定** → サムネイルフォルダー）を確認してください

### WhiteBrowser カスタムスキンの配置

カスタムスキンは **`IndigoMovieManager.exe` と同じフォルダ** に次の形でコピーします。

```text
IndigoMovieManager.exe
Skins/
  WbHost/
    <スキン名>/
      <スキン名>.htm
      <スキン名>.css
      （画像などの付属ファイル）
```

- WhiteBrowser 側のスキンフォルダを、そのまま `Skins/WbHost/<スキン名>/` へコピーする
- **フォルダ名と htm/css のファイル名が一致**している必要がある（例: `MySkin/MySkin.htm`）
- ヘッダーで **WhiteBrowser 互換** を選び、ドロップダウンからスキン名を選択する

### その他の注意

- **初回オープン・スキン切替で自動サムネ生成**が走ります。件数が多いと時間がかかります
- **監視フォルダ**が DB に登録されていると、起動後にフォルダ走査が動きます。テスト用コピー DB でも設定を確認してください
- **完全互換ではありません**。検索・スキン・一部操作は WhiteBrowser と異なります
- **`sinku` / `ffmpeg` は同梱されません**（後述「外部ツール」）

### WhiteBrowser 互換スキンでできること・できないこと

#### 一覧（WhiteBrowser スキン）でできること

| 操作 | 補足 |
|------|------|
| スキンどおりの一覧表示 | 同梱・カスタムスキンとも |
| クリックで選択 | スキン設定で複数選択が有効なら Ctrl・Shift も可 |
| **サムネイルのダブルクリックで再生** | 複数パネルサムネではクリック位置から再生開始位置を推定 |
| 一覧内タグのリンク | そのタグで検索 |
| 一覧内タグの [x] | タグ削除 |
| 矢印・Home/End・PageUp/PageDown | 一覧内の移動・スクロール |
| ZIP のダブルクリック | ZIP ビューアで開く |

#### 一覧（WhiteBrowser スキン）でできないこと

| 操作 | 補足 |
|------|------|
| **一覧上の右クリックメニュー** | **使えません**（再生・タグ編集・ファイル操作など） |
| 一覧からの等間隔サムネ・マニュアルサムネ | 右クリック経由のため不可 |
| ヘッダーの **Reload**（スキン再読込） | Indigo ネイティブ（WPF）スキン専用 |

#### 代替手段（WhiteBrowser スキン利用中）

- **詳細ペインのサムネイル** — 右クリックメニューが使えます
- **キーボード** — Enter（再生）、F6（タグ編集）、F2（リネーム）、Delete（登録削除）など
- **ヘッダー** — 検索、ソート、**更新**
- **ハンバーガーメニュー** — 設定、監視フォルダ、ツール

## はじめて使う

1. アプリを起動する
2. 左上の **ハンバーガーメニュー** → **ファイルを開く** で管理ファイル（`.wb`）を選ぶ
3. 中央に動画一覧、右側に詳細ペインが表示されます
4. ヘッダーの検索ボックス・ソート・スキン切替を使って一覧を操作します

**新規作成** はハンバーガーメニューから。最近開いたファイルも同メニュー内に表示されます。

## 画面構成

### ハンバーガーメニュー（左上）

| 項目 | 内容 |
|------|------|
| 新規作成 | 新しい管理ファイル |
| ファイルを開く | 既存の `.wb` 等を開く |
| 最近開いたファイル | 履歴から開く（右クリックで履歴から削除） |
| 共通設定 | プレイヤー既定値、監視拡張子など |
| 個別設定 | 開いている DB 専用（サムネ・ブックマークフォルダなど） |
| 監視フォルダ編集 | フォルダ監視の登録 |
| 監視フォルダ更新チェック | 手動で監視フォルダを走査 |
| 全ファイルサムネイル再作成 | 一覧の全件をサムネ再生成キューへ |
| 全ファイル情報再取得 | sinku 利用（要外部ツール） |
| 終了 | アプリ終了 |

### ヘッダー

- **検索ボックス** — キーワード入力で自動絞り込み（約 0.4 秒）。**Enter** で明示検索・履歴反映。履歴はドロップダウンから選択
- **保存済み検索（TagBar）** — よく使う検索条件をチップとして保存・クリックで適用
- **ソート** — 並び順の変更
- **更新** — DB 再読込・一覧の強制更新（サムネ生成も再開）
- **スキン切替** — **Indigo**（ネイティブ WPF）/ **WhiteBrowser 互換**
- **スキン名ドロップダウン** — 各モード内のスキン選択
- **Reload** — **Indigo スキンのみ**（`skin.json` 編集後の再読込）

### メインエリア

- **一覧** — 選択したスキンで動画が並ぶ
- **詳細ペイン** — 選択中レコードのサムネ・メタ情報。ファイル名クリックで検索

### ブックマーク

下部タブのブックマーク一覧から、保存したシーンの再生・削除ができます。

## 検索の使い方

1. 検索ボックスにキーワードを入力すると、**約 0.4 秒後**に一覧が自動で絞り込まれます（インクリメント検索）
2. **Enter** で明示検索（履歴に残す・サムネ生成スコープを更新）
3. 検索をクリア（テキストを空にする）すると全件表示に戻る
4. 詳細ペインの **ファイル名** をクリックすると、その名前で検索できる
5. 検索履歴の削除: ドロップダウンを開き、項目上で **Ctrl+Delete**

**インクリメント検索の対象外:** `{tag = ''}` や `{::error}` など、**先頭が `{` の構文**は入力中は絞り込みません。**Enter** で実行してください。

### 検索構文

| 構文 | 説明 |
|------|------|
| 通常キーワード | ファイル名・パス・コメントは部分一致。タグはタグ単位の完全一致 |
| スペース区切り | AND 検索 |
| `\|` 区切り | OR 検索 |
| `!キーワード` | タグの完全一致 |
| `-キーワード` | 除外 |
| `{tag = ''}` など | SQL の WHERE 句（`INSERT`/`UPDATE`/`DELETE`/`;`/`--` は無効） |
| `{::duplication}` | ハッシュ重複のみ |
| `{::nofile}` | 実ファイルがないレコード |
| `{::error}` | 現在のスキンで error サムネが表示されているレコード |

例: `★★★` は `★★★` タグのみヒットし、`★★★★★` はヒットしません。

### 保存済み検索条件（TagBar）

- 検索ボックス横の **保存** で現在の検索をチップ化
- チップをクリックでその条件を適用
- チップを右クリック: 名前変更 / 検索条件を編集 / 複製 / 削除

## ソート

## サムネイル

### 自動生成

- **スキン切替**（Indigo / WhiteBrowser、スキン名変更）時に、未作成サムネを自動で生成します
- 件数が多いときは、先にステータスバーに「サムネイル確認中 (スキン名)」と表示されます
- **Enter や履歴選択などで検索キーワードを確定したとき**、進行中の生成は止まり、**表示中の絞り込み結果**（未作成のみ）向けに再開します（入力中のインクリメント検索では再起動しません）
- **検索をクリア**するとライブラリ全体を対象に再開します
- `{::error}` で 0 件のときは生成は止まり、新規開始もしません
- DB の再読込や強制更新が必要なときはヘッダーの **更新** を押してください

### 手動作成

| 方法 | 操作 |
|------|------|
| 等間隔サムネイル | 一覧で右クリック → **等間隔サムネイル作成**（**Indigo スキンのみ**。複数選択可） |
| マニュアルサムネイル | 右クリック → **マニュアルサムネイル作成** → プレビュー小窓で位置を決めて取得 |

WhiteBrowser スキン表示中は一覧の右クリックが使えないため、**Indigo スキンに切り替える**か、**詳細ペインのサムネ**を右クリックしてください。

### 進捗表示

サムネ作成中はステータスバーに `完了数/総数` とファイル名が表示されます。

## スキンの種類（Indigo と WhiteBrowser）

| | Indigo（WPF） | WhiteBrowser 互換 |
|--|---------------|-------------------|
| 配置 | `Skins/Wpf/<名前>/skin.json` | `Skins/WbHost/<名前>/<名前>.htm` |
| 切替 | ヘッダー「Indigo」+ ドロップダウン | ヘッダー「WhiteBrowser」+ ドロップダウン |
| 一覧右クリック | 利用可 | **利用不可** |
| ダブルクリック再生 | 可 | **可** |
| 編集後の反映 | **Reload** ボタン | スキンフォルダを差し替えてドロップダウンで再選択 |

### 負荷の目安

- Indigo の **`WideGridInfo`** は表示・サムネ生成とも負荷が高いです。初回テストは **`DefaultSmall`** / **`DefaultGrid`** など軽いスキンか、レコードの少ない DB を推奨します
- WhiteBrowser 側もスキン・件数によって負荷は変わります

WPF スキンの自作: [Skins/Wpf/README.md](Skins/Wpf/README.md)

| キー | 動作 |

## ブックマーク

1. マニュアルサムネのプレビュー中、または一覧で動画を選んだ状態でブックマークを追加
2. 下部のブックマークタブで一覧表示
3. ラベルをクリックしてブックマーク位置から再生

ブックマーク画像の保存先は **個別設定** のブックマークフォルダーで変更できます（空のときは `bookmark/<DB名>/`）。

## ファイル操作

一覧（Indigo スキン）または **詳細ペインのサムネ** を右クリック:

| メニュー | 内容 |
|----------|------|
| プレイヤーから開く / サムネイルから開く | 外部プレイヤーで再生 |
| ファイル情報再取得 | sinku でメタデータ更新（要外部ツール） |
| 登録から削除 | DB からレコード削除（ファイル自体は残る） |
| ファイルをコピー / 移動 / 削除 / 名前変更 | 実ファイル操作 |
| 親フォルダを開く | エクスプローラーで表示 |

キーボード: **Enter**（再生）、**F2**（リネーム）、**Delete**（登録削除）、**F12**（親フォルダ）

## 設定

### 共通設定（全 DB 共通）

- 起動時に最後に開いた管理ファイルを開く
- 既定の再生プレイヤー・パラメータ（`<ms>` / `<file>` 置換）
- 既定の ZIP ビューア
- 終了時の確認
- サムネイル作成の並列数
- FFmpeg ハードウェアデコード（フォールバック時）
- 監視・走査対象の拡張子（カンマ区切り。例: `.mp4,.mkv,.zip`）
- 最近開いた管理ファイルの表示件数

### 個別設定（開いている DB のみ）

- サムネイルフォルダー
- ブックマークフォルダー
- 再生プレイヤー・パラメータ（この DB 用）
- 検索履歴の保持件数
- 除外拡張子（共通の走査対象から除外。例: `.zip,.jpg` — 動画フォルダ内の ZIP を除外したい場合など）

## 監視フォルダ

1. ハンバーガー → **監視フォルダ編集** でフォルダとサブフォルダ可否を登録
2. 新規ファイルの検出・登録は自動（拡張子は共通設定・個別設定に従う）
3. **監視フォルダ更新チェック** で手動走査

## 外部ツール（任意）

アプリ単体でも基本操作は可能です。以下は **同梱されません**。必要に応じて各自で配置してください。

### sinku（メディア詳細情報）

`IndigoMovieManager.exe` と **同じフォルダ** に 4 ファイルをセットで配置:

- `sinku.exe` / `Sinku.dll` / `format.ini` / `codecs.ini`

未配置時は **ファイル情報再取得** メニューが無効になります。

### ffmpeg（サムネイル生成の補助）

```text
IndigoMovieManager.exe
ffmpeg/
  ffmpeg.exe
  ffprobe.exe
```

OpenCV でサムネ生成に失敗した場合のフォールバックなどに使います。未配置でも起動は可能ですが、一部形式はプレースホルダ画像になることがあります。
