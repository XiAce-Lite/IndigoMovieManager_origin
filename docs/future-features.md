- WhiteBrowser 互換のため、表示順は `order_id` → `item_id` の順で読み込む（現状どおり）

### インポート / エクスポート

- 保存済み検索条件だけを JSON や CSV 等でエクスポート
- 他の DB やバックアップからインポート
